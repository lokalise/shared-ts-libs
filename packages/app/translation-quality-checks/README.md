# @lokalise/translation-quality-checks

Deterministic, code-based quality checks for translations — given a source and a target text, detect
segment-level quality issues (inconsistent placeholders/tags, whitespace problems, …). Pure string
operations with no I/O, so the same checks run identically in the browser, in Node services, and in
any other consumer.

> 🚧 **Work in progress.** The package is being built as part of the Vantage QA checks initiative
> (EXP-2307) and does not expose any checks yet.
